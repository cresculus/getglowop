→ One-click deploy

One click per client. Every device in the right business.

Open a business in the partner console and press Deploy. Push straight to that client's Intune, download an RMM script that is already set to join, or hand any Windows PC a one-click installer. No copying keys, and no spreadsheet of which password goes with which client.

  1. 1

    Intune →

    Push to Intune, one click. A Global Admin of the client's Microsoft 365 approves GlowOps once. After that, Deploy uploads a Win32 app to that client's Intune with the install, uninstall, and detection rules already set, and assigns it to all devices or to one group. Rather upload it yourself? Download the ready-made .intunewin with its settings sheet.

  2. 2

    RMM →

    A script that is ready to join. One PowerShell file per client, with the dashboard URL and join key for that business already inside. Drop it into the client's script library in NinjaOne, Datto, ConnectWise, or N-able and run it as SYSTEM. It installs the agent, joins, and schedules check-ins.

  3. 3

    Any PC ✓

    One-click install for everything else. A loaner, a home office, or a client with no MDM at all. Unzip, double-click Install GlowOps.cmd, and approve the admin prompt. That PC reports to the right business within minutes.

Built for a hundred clients, not one

The Businesses page shows every client as a card, with devices, average GLOW™, ghosts, last check-in, and where it stands: not deployed, collecting, or report ready. Search, filter, sort, pin the ones you watch, or switch to a table. Deploy sits on every card.

How the key stays safe

Every download creates a new join key for that business only, valid for 7 or 30 days. GlowOps keeps a hash, never the password. A package can only join devices to the business it was made for. Keys expire on their own, every download is logged, and you can revoke any key from the same screen. Only owners, admins, and operators on that business can deploy.
