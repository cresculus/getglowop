04 How a real report gets made

Many ways in. A decision out.

No new silo and no power-spy. Intune, RMM, and agent-based ingest are all available. Intune-heavy or SCCM-heavy shops get a path that respects what they already run. Four steps, with the honest limits printed on each one.

  1. 1

    Ingest →

    Intune when that is the system of record. An RMM when that already owns the box. A thin agent when there is no management tool. SCCM when the estate is still ConfigMgr-first. One-click deploy, packaged for that company only.

  2. 2

    Enrich →

    Each row carries a manufacturing factor. The source of that factor is named.

  3. 3

    Decide →

    Security and a dead machine still win.

  4. 4

    Report ✓

    One GLOW Op Report per client. Portfolio view for the MSP. PDF and CSV. The MSP’s logo, if they want their name on the joke.

The call

Keep, repair, or replace. The calendar is not the decision.

Haul-away

Physical haul-away is a partner. Someone else with a certification takes the dead ones.
