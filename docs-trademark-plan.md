## Classes to file (per mark)

USPTO base fee is **$350 per class** (2025+ single base application; TEAS Plus is gone). Prefer ID Manual entries to avoid the $200 free-form fee.

| Class | Why |
| --- | --- |
| **42** | SaaS / online non-downloadable software (dashboard, report) |
| **9** | Downloadable agent (`GlowOpsAgent.exe`) if you claim that under the same mark |

**Budget (government only, rough):**

- GLOW — Class 42 (+ optional 9) → $350–$700  
- GLOW Ops — Class 42 (+ optional 9) → $350–$700  
- GLOW Op Report — Class 42 → $350

Attorney search + filing typically adds more; DIY is allowed but Office Actions are common.

## Filing order (do this)

1. **Clearance search** — USPTO Trademark Search for GLOW, GLOW OPS, GLOWOP, Green Lifecycle in Classes 9/42. Screenshot conflicts.
2. **Specimens** — Live site screenshots showing the mark on the service (getglowop.com hero, dashboard GLOW column, PDF cover when you have one). Agent icon for Class 9.
3. **Owner** — Augmatic Holdings LLC, EIN on file, correspondence email you monitor.
4. **Basis** — Section **1(a) use in commerce** if the mark is already live on the site/app; else **1(b) intent-to-use**.
5. **File** each mark (one mark per application). Keep ID Manual wording close to:  
   *Software as a service (SAAS) services featuring software for IT asset lifecycle scoring and fleet refresh decision support.*
6. **Watch** — docket Office Actions (response deadlines are hard). After registration, file maintenance (Years 5–6, 9–10, etc.).

## Do not

- Claim you “trademarked the idea” or the algorithm.  
- Put ® before registration.  
- File under a personal name if Holdings should own the IP.  
- Overclaim tax credits on the marketing site beyond what a CPA would endorse (site already disclaims tax advice).
